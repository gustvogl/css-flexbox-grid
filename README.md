# Halloween

## Origens
O *Halloween* tem suas **raízes antigas** nas celebrações celtas do festival de *Samhain*, que marcava o fim do verão e o início do inverno. Nessa época, acreditava-se que os espíritos dos mortos podiam visitar o mundo dos vivos. Com o passar do tempo, tradições pagãs e cristãs se misturaram, dando origem ao Halloween como conhecemos hoje.

## Tradições Modernas
Atualmente, o Halloween é comemorado em diversos países com **muitas tradições divertidas**, que envolvem fantasias, festas e decorações assustadoras. Algumas das mais populares são:

- **Doces ou travessuras** (*Trick or Treat*), em que as crianças visitam casas pedindo guloseimas.  
- *Fantasias criativas*, desde personagens assustadores até heróis e figuras populares.  
- **Abóboras iluminadas**, chamadas de *Jack-o’-lanterns*, usadas para enfeitar as casas e ruas.

# Projeto CSS Flexbox e Grid

## Introdução
O *projeto CSS Flexbox e Grid* foi desenvolvido para demonstrar **os principais conceitos de layout responsivo** utilizando as técnicas modernas do **CSS3**. Ele apresenta exemplos práticos de como alinhar, distribuir e organizar elementos em uma página da web com **Flexbox** e **CSS Grid Layout**.

## Estrutura do Projeto
O diretório principal contém vários arquivos HTML e um arquivo principal de estilo (`style.css`).  
A seguir está uma visão geral da estrutura:

- **index.html** — página inicial do projeto.  
- **flexbox.html** — exemplo principal com uso de contêineres flexíveis.  
- **flexbox-ex1.html**, **flexbox-ex2.html**, **flexbox-ex3.html** — variações práticas mostrando propriedades como *justify-content*, *align-items* e *flex-wrap*.  
- **grid.html** — exemplo completo de **CSS Grid**, destacando o uso de *grid-template-columns* e *grid-gap*.  
- **sobre.html** — página com informações adicionais sobre o projeto.  
- **style.css** — arquivo de **folha de estilo principal**, responsável pela aparência e formatação das páginas.  
- **img/** — pasta com capturas de tela e imagens ilustrativas.

## Conceitos-Chave
O projeto explora dois módulos fundamentais do CSS:

### 1. Flexbox
O **Flexbox** (*Flexible Box Layout*) é ideal para criar layouts em uma única dimensão — linha ou coluna. Ele facilita o alinhamento de elementos, a distribuição de espaço e a responsividade.

Principais propriedades utilizadas:
- `display: flex;`
- `justify-content: center;`
- `align-items: stretch;`
- `flex-wrap: wrap;`

### 2. CSS Grid
O **CSS Grid Layout** trabalha com duas dimensões — linhas e colunas. Ele oferece maior controle sobre a posição dos elementos na página, sendo ótimo para estruturas mais complexas.

Principais propriedades demonstradas:
- `display: grid;`
- `grid-template-columns: repeat(3, 1fr);`
- `grid-gap: 20px;`

## Conclusão
Este projeto serve como uma **ferramenta de aprendizado prática** sobre como aplicar *Flexbox* e *Grid* para construir layouts modernos e responsivos.  
O uso combinado dessas técnicas permite criar **interfaces elegantes, organizadas e adaptáveis** a diferentes tamanhos de tela.
