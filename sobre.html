Este projeto foi desenvolvido por Gustavo Luis com o objetivo de demonstrar o uso das tecnologias CSS Flexbox e CSS Grid em layouts modernos e responsivos, tudo com uma ambientação temática de Halloween 🎃.

📘 Flexbox

O Flexbox é usado para alinhar elementos de forma flexível em uma única dimensão (horizontal ou vertical). Ideal para menus, cartões e pequenas seções onde os elementos precisam se ajustar automaticamente.

📗 CSS Grid

O CSS Grid é um sistema de layout bidimensional que permite organizar itens em linhas e colunas. É excelente para criar grades completas, galerias e estruturas de página mais complexas.
